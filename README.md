# 🏴‍☠️ Grand Line Bounty Board & Management System

An interactive command-line application built with **Python** and **JSON** that tracks, searches, and dynamically updates an elite anime target database. 

## ⚡ Features
* **Interactive Terminal Control Center:** Menu-driven interface for seamless navigation.
* **Persistent JSON Data Storage:** Automatically writes and saves new targets directly to disk (`bounty_data.json`).
* **Dynamic Search Engine:** Filter targets instantly by name or epitaph.
* **Error-Resilient File Handling:** Gracefully checks for file existence and malformed structures.
